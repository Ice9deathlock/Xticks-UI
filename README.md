# xTicks CFD UI

Standalone static UI for the Hyperticks trading platform.

## Pages

- `index.html` — Profile Settings (account details, personal info, password update). Uses `styles.css` and `script.js`.
- `dashboard.html` — Trader Dashboard (account stats, activity chart, trading history). Self-contained with inline styles and script.

Open either file directly in a browser, or serve the folder with any static server.
